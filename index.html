This website has a server (for registrations, referrals, merch orders and the admin dashboard), so it can't run by opening an HTML file. Start it like this:

  1. Install Node.js (LTS version) if you don't have it.
  2. Windows: double-click start.bat
    Mac: double-click start.command
  3. The site opens at http://localhost:3000 — keep the black window open while using it.
